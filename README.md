# House Price Prediction — Linear Regression

## Overview
This project implements a Linear Regression model to predict house prices based on features such as house area and number of rooms.

The model is trained using Gradient Descent to learn the parameters that minimize prediction error.

## Features
- Data loading and preprocessing using Pandas and NumPy.
- Linear Regression implemented using Gradient Descent.
- Feature Scaling to improve training stability.
- House price predictions based on input features.
- Model evaluation using MAE and RMSE.
- Data visualization using Matplotlib.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib

## Dataset
The dataset contains housing information, including:
- Area
- Number of rooms
- House price

## How to Run

1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install numpy pandas matplotlib
   ```
3. Run the Python script:
   ```bash
   python home.py
   ```

Make sure the dataset file is available at the path expected by the script.
